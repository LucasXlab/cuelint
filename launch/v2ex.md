# V2EX 草稿

节点建议：分享创造 / 程序员

标题：做了个本地字幕体检 CLI：检查并修复 SRT/VTT，输出一份 HTML 报告

正文：

每周发口播视频，自动生成的字幕字基本对，但排版经常没法看：一行一百多个字、两条字幕叠 100ms、一句只停 500ms、语速 20 字/秒。

CueLint 是一个 Python 命令行工具，跑 13 条规则，能确定修的就修，不能修的在报告里标出来：

- 删除空字幕、相邻重复字幕、控制字符；
- 消除重叠，补最小间隔和最短停留；
- 在不越界的条件下延长过快字幕；
- 重新断行，超长时拆段；
- 生成单文件 HTML 报告，浅色/深色、375px 可用。

```bash
pipx install .
cuelint fix episode-07.srt --report report.html
```

不联网、不上传、不需要账号、不读音视频；只支持 SRT / WebVTT。默认 `cjk` 档是 36 列、2 行、9 字/秒，另有 `latin`、`presentation`、`strict`。

目前 0.1.0，MIT，88 个离线测试。想听真实使用反馈：默认值是否适合你的语言/平台，报告哪里不好读，下一条最该自动修的规则是什么。
