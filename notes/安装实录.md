# 安装实录

日期：2026-10-29
环境：macOS，Apple Silicon，Python 3.13.5，pip 25.1.1，pipx 未安装。

## 步骤

从已提交的本地仓库克隆到空目录，按 README 的 `pip install .` 路径安装：

```bash
git clone . /tmp/cuelint-clean
cd /tmp/cuelint-clean
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
cuelint --version
```

输出：

```text
cuelint 0.1.0
```

pip 提示缓存目录不可写（本机权限问题，与项目无关），安装退出码 0。

## 冒烟

```bash
cuelint check examples/demo.zh.srt
```

退出码 1，输出 8 条字幕、错误 3、警告 6，逐条列出重叠、过短、CPS、行宽等问题。

```bash
cuelint fix /tmp/cuelint-runs/demo.zh.srt --force --report /tmp/cuelint-runs/report.html
```

退出码 1（仍有 1 个错误、3 个警告，均为无法安全修复）；修复 5 处；生成 `demo.zh.fixed.srt` 和 `report.html`。

## 幂等

对修复结果再跑一次 fix：修复 0 处，输出 `.fixed.fixed.srt` 与 `.fixed.srt` 字节相同（`diff -q` 无输出）。

## JSON

`cuelint check --format json` 返回 `tool=cuelint`、`version=0.1.0`，summary 为 1 个文件、修复前后均 1 错误 3 警告、0 修复。
